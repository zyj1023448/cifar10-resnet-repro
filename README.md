# CIFAR-10 Residual Learning and Channel Attention Reproduction

Code, training logs and trained weights for the paper **“残差学习与通道注意力在 CIFAR-10 图像分类中的复现与实证分析”** (Residual Learning and Channel Attention for CIFAR-10 Classification: A Reproduction and Empirical Analysis).

**Paper:** `paper/CIFAR10_ResNet_SE_复现与实证分析.pdf`  
**Code and weights:** https://github.com/zyj1023448/cifar10-resnet-repro

This is a deliberately small, single-GPU reproduction. It is **not** a new architecture paper: it asks how much of the gain of a residual network comes from the residual path, and how much channel attention adds on a 0.27M-parameter CIFAR backbone under a fixed 100-epoch budget.

## Reference papers

- **Primary reproduction:** He K, Zhang X, Ren S, Sun J. *Deep Residual Learning for Image Recognition.* CVPR 2016: 770-778 (CIFAR-10 depth comparison, Table 6).
- **Attention module:** Hu J, Shen L, Sun G. *Squeeze-and-Excitation Networks.* CVPR 2018: 7132-7141 (SE block, reduction ratio).
- Additional references: pre-activation ResNet (ECCV 2016), Mixup (ICLR 2018), label smoothing (CVPR 2016; NeurIPS 2019), cosine annealing (ICLR 2017), CIFAR-10-C (ICLR 2019).

## Results at a glance

| Method | Test acc (%) | Macro-F1 (%) | ECE | NLL | Params (M) | Train (min) | Seeds |
|---|---:|---:|---:|---:|---:|---:|---:|
| Plain-20 | 90.56 ± 0.31 | 90.55 | 0.0545 | 0.3736 | 0.270 | 5.3 | 3 |
| ResNet-20 | 91.66 ± 0.08 | 91.66 | 0.0478 | 0.3350 | 0.272 | 5.6 | 3 |
| SE-ResNet-20 | 91.75 ± 0.10 | 91.74 | 0.0454 | 0.3181 | 0.277 | 6.8 | 3 |

- Residual gain over the plain baseline: **+1.10 pp** (McNemar p = 0.006958; bootstrap 95% CI [0.18, 1.31] pp).
- SE gain over ResNet-20: **+0.08 pp** (p = 0.5598; CI [-0.38, 0.71] pp), but ECE drops from 0.0478 to 0.0454.
- Depth 56: the plain network degrades, the residual network improves. See `results/figures/fig_depth.png`.
- Mixup adds **+0.55 pp** on top of SE-ResNet-20; pre-activation adds +0.25 pp but with larger seed variance.
- Label smoothing *hurts* both accuracy (91.34%) and calibration (ECE 0.0585) at this budget.

## Repository layout

```text
src/          data, models, training loop, metrics, analysis, Grad-CAM
scripts/      dataset preparation, experiment grid, reproduce.ps1/sh, keep-awake helper
weights/      one .pt per run (state_dict + config + final metrics)
results/runs/ per-run JSON (config, per-epoch history, final metrics)
results/preds/per-sample test logits and labels (.npz)
results/figures/paper figures (PNG, 200–300 dpi)
results/tables/ CSV tables used in the paper
paper/        DOCX/PDF and the scripts that build them
data/         CIFAR-10 cache (git-ignored; regenerated by scripts/prepare_cifar.py)
```

`weights/` contains 26 checkpoints. `weights/plain20_s42.pt` is the plain baseline; `weights/se20_s42.pt` is the proposed SE-ResNet-20; `weights/resnet20_s42.pt` is the reproduced ResNet-20. Each checkpoint stores `state_dict`, the training config and the final metrics.

## Quick start

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/prepare_cifar.py    # downloads CIFAR-10 (~135 MB) and caches tensors
python scripts/run_grid.py         # 25 runs, ~3 h on one RTX 5060 Laptop GPU
python -m src.analyze              # tables, figures, McNemar/bootstrap, robustness
python paper/build_paper.py        # regenerate the DOCX from results/summary.json
```

To check the committed artefacts without retraining:

```bash
python scripts/validate_results.py
```

## Environment

- NVIDIA GeForce RTX 5060 Laptop GPU (8 GB), CUDA 12.8, PyTorch 2.11.0+cu128, Python 3.13.
- 100 epochs, batch 256, SGD (momentum 0.9, Nesterov), weight decay 5e-4, cosine schedule with 5-epoch warmup, bfloat16 autocast.
- 20-layer runs take 5–7 min; 56-layer runs take 17–19 min. Results are the last-epoch test accuracy (no test-time model selection), averaged over seeds.
